## 📥 این پروژه چیکار میکنه؟

با این پروژه می‌تونی **هر ویدیوی یوتیوب** رو با چند کلیک ساده دانلود کنی و مستقیماً توی ریپازیتوری گیت‌هاب خودت ذخیره کنی.  
فایل‌های حجیم به‌طور خودکار تکه‌تکه می‌شن، زیرنویس فارسی و انگلیسی دریافت می‌شه، و حتی می‌تونی با رمز از ویدیوهات محافظت کنی. **بدون هیچ هزینه‌ای و کاملاً رایگان!** 🎉

---

## ✨ امکانات ویژه

- 🎯 **دانلود با بالاترین کیفیت** (۴K، ۲K، 1080p و حتی فقط صوت)
- 🌐 **دور زدن تحریم‌ها** با پروکسی هوشمند Cloudflare WARP
- 🧩 **تقسیم خودکار فایل‌های بزرگ** به قطعه‌های ۴۵ مگابایتی متناسب با محدودیت گیت‌هاب
- 📝 **دریافت زیرنویس فارسی و انگلیسی** (و ترجمه خودکار در صورت نبود زیرنویس)
- 🔒 **محافظت با رمز عبور** روی فایل‌های زیپ
- 🖼️ **ذخیره خودکار تصویر شاخص (thumbnail)**
- 📄 **ساخت فایل README برای هر ویدیو** همراه با لینک دانلود مستقیم
- 🧹 **پاکسازی یک‌جا** برای خلوت کردن ریپازیتوری

---

## 🚀 شروع سریع – فقط ۳ قدم!

### ۱. ریپازیتوری رو فورک کن
- اول از همه این پروژه رو فورک کن
- **مهم:** مطمئن شو که تو تنظیمات Actions گزینه **Read and write permissions** فعال باشه (Settings > Actions > General > Workflow permissions)


### ۳. ویدیو دانلود کن! 🎉
- وارد تب **Actions** توی ریپازیتوری شو
- روی **"01 - 🎬 دانلود ویدیو"** کلیک کن
- دکمه **Run workflow** رو بزن
- **لینک ویدیو** رو وارد کن (اگه چندتاست، با فاصله جدا کن)
- کیفیت، زیرنویس و رمز رو (اختیاری) تنظیم کن
- **Run workflow** رو بزن و منتظر بمون

پس از پایان کار، ویدیوها داخل پوشه `videos/` ریپازیتوری قرار می‌گیرن و می‌تونی از README هر ویدیو لینک دانلود مستقیم برداری.

## 🎮 راهنمای کامل استفاده

### 🎚️ تنظیمات دانلود

| پارامتر | توضیح | مقادیر مجاز |
|--------|-------|------------|
| `video_urls` | لینک یوتیوب (چندتایی با فاصله) | آدرس کامل ویدیو |
| `quality` | کیفیت دانلود | `best` (پیش‌فرض), `2160`, `1440`, `1080`, `720`, `480`, `audio` |
| `download_subtitles` | دانلود زیرنویس | `true` یا `false` |
| `password` | رمز فایل زیپ (اختیاری) | متن دلخواه |
